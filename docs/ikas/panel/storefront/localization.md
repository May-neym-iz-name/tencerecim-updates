# Localization

`(Dashboard Navigation Menu > Sales Channels > Your Storefront Name > Localization)`.
Localization settings can be defined specifically for each region as well as the country.
It allows our users to create different routes for their storefronts.
By doing this, they can sell their products globally in the desired language and price list if they want.
info
If you are looking for a way to check your theme in different language/currency options as a theme developer, you need to define
these region-specific settings first.
