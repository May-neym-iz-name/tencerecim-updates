# Translations

Translations allows you to create translations for your components, custom data types, colors and groups.
When you create your components, you are being asked to provide `Display Names`, which are user friendly texts
that are being displayed to the end users. However, you are only able to provide these in a single language.
In the translations section, you can add new languages to support and provide translated values for all of the
texts.

note
Currently, ikas dashboard only supports Turkish, English, French and Deutsch. If you translate your components for this languages
it would be enough for now. However if you want to future proof your theme, you can add other languages as well.
