# Introduction

Theme settings is where you and the merchants select some global settings for the theme.
Here are the available settings;

- Generic Settings
- Colors
- Fonts
- Translations
These settings will be passed to all of your components defined in the editor
as a prop value with the `settings` key. Settings is an instance of the IkasThemeJsonSettings class.
