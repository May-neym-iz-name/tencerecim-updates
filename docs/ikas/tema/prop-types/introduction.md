# Introduction

In this section, we will describe all the data types that you can use as a prop type. You don't have to read them all in order, or all at once.
As you keep creating your components, come back here to learn about which data type you need, and how they work.
Here is the list of all prop types currently available;

- Text
- Rich Text
- Boolean
- Image
- Image List
- Link
- Link List
- Product
- Product List
- Attribute
- Attribute List
- Brand
- Brand List
- Category
- Category List
- Color
- Component
- Component List
- Blog
- Blog List
- Blog Category
- Blog Category List
- Number Select Slider
- Custom Data Types
