# IkasAttributeList

`product`IkasProduct | null

Refer to the IkasProduct reference.

`attributeListPropValue`IkasAttributeListPropValue

This is a raw internal prop value data provided from the theme editor.

`values`IkasProductAttributeMap[]

This is the field to you use when you want to render attributes of a product.
You can map over this array and render each attribute and its values.
Refer to the IkasProductAttributeMap reference.
