# Publishing a Theme

Publishing themes to all ikas merchants are currently disabled, since the theme development is in beta.
You can however, upload and publish your theme to specific stores by following the steps from the
Allowed Stores page.

## Uploading Theme Source Code
To upload your theme, you need to first make sure that the theme builds properly.
Run the `yarn build` command, and if the build is successfull, your theme is ready to upload.
Make sure you have the correct credentials set for your theme.
Go to the theme editor, and click on the `Upload Theme` button.

The upload process will begin and you can check the build status from the theme versions
page.
